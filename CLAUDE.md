# Cómo trabajar en este repo

- El dueño es Ale (Alexis). No es técnico, usa el teléfono y escribe en castellano rioplatense:
  respuestas cortas, simples y sin jerga.
- **Publicar solo.** Ale pidió no tener que hacer pasos en GitHub ni en Vercel. Cuando un cambio
  está terminado y probado: subirlo, crear el pull request y hacer el merge a `main` (Vercel
  publica solo con el merge). Después contarle qué cambió y qué probar, nada más.
- Pedirle algo a Ale solo cuando no hay otra forma (por ejemplo, una clave nueva en Vercel), en
  pocos pasos numerados.
- Las claves y tokens van solo en Vercel → Settings → Environment Variables, nunca en el código.
