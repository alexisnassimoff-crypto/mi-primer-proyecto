CÓMO SUBIRLOS POR LA WEB DE GITHUB (sin instalar nada):
1. Entrá a github.com/alexisnassimoff-crypto/central-eyewear-crm
2. Apretá la tecla . (punto) NO — más simple: botón "Add file" → "Upload files"
3. Arrastrá las carpetas api y public y los archivos package.json
   (GitHub respeta las carpetas al arrastrar)
4. Abajo elegí "Commit directly to the main branch" → "Commit changes"
5. Vercel detecta el push y deploya solo (~1 minuto)
6. Probá en central-eyewear-crm.vercel.app con un usuario vendedor

de tu ZIP de backup de la misma manera.
