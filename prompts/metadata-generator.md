# Generador de metadata de YouTube

Produce título, descripción y tags optimizados para SEO infantil. **Made for Kids = ON**
siempre (COPPA). Recordá: en "Made for Kids" NO hay comentarios ni cards; el SEO va todo
en título + descripción + tags + miniatura.

## Título

Formato: `<TEMA clave> <emoji> | <gancho corto> | Lumo & Friends`
- Empezar con lo que buscan los padres (ABC Song, Numbers Song, Colors Song, Lullaby...).
- 1 emoji relevante. < 70 caracteres para que no se corte.

## Descripción (plantilla)

```
<1 línea que describe la canción y el beneficio para el niño>.
Sing along with <personaje> in Glimmerwood! 🌟

🎵 More songs: <link playlist>
🔔 Subscribe for a new song every day!

00:00 <si es compilado, timestamps de cada canción>

#<hashtag1> #<hashtag2> #forkids #nurseryrhymes
```

## Tags (10–15, mezcla de amplios + específicos)

- Amplios: `kids songs, nursery rhymes, toddler songs, preschool, songs for kids, baby
  songs`
- Marca: `lumo and friends, lumo, glimmerwood`
- Específicos del tema: p.ej. `abc song, alphabet song, learn abc` / `counting song,
  numbers song` / `lullaby, bedtime song, sleep song for babies`.

## Reglas

- Nunca prometer cosas falsas ni clickbait engañoso (penaliza y rompe confianza).
- Coherencia de marca en cada título (`| Lumo & Friends`).
- Para compilados: incluir timestamps (sube retención y da rich results).
- Miniatura según plantilla en `brand/brand.md`.
